
# Paradise Nursery

Paradise Nursery is an online plant shopping application developed using React.

## Features
- Attractive landing page
- Plant product listing
- Plant categories and prices
- Add to Cart functionality
- Increase and decrease product quantities
- Remove products from cart
- Automatic total price calculation
- About Us section

## Technologies Used
- React.js
- Vite
- Redux Toolkit
- React Redux
- CSS

## How to Run
1. Clone this repository.
2. Run npm install.
3. Run npm run dev.
4. Open the localhost URL in your browser.
